# Cubeborn

Воксельная RPG для браузера (Vite + TypeScript + Three.js). Сейчас это основа: тренировочная
поляна 100 × 100 с тремя манекенами, раса «Человек», 7 видов оружия, щит, 3 комплекта брони,
инвентарь и экипировка. Подробности, таблицы чисел и как добавить расу — в
[docs/rpg/README.md](docs/rpg/README.md).

## Запуск

```bash
npm install
npm run dev        # локально: http://localhost:5173
npm run build      # продакшен-сборка в dist/
npm run preview    # проверить сборку
npm test           # тесты
```

`dist/` — статический сайт для любого хостинга.

## Управление

ЛКМ по земле — идти (обход препятствий и подъём по ступеням), ЛКМ по манекену — выбрать цель,
ЛКМ по выбранной цели — автоатака (герой сам подходит на дистанцию оружия), зажатая ПКМ + мышь —
вращать камеру вокруг героя и менять наклон (25–50°), Пробел — прыжок (ещё раз в воздухе —
двойной), F — атака, Tab / I — инвентарь, M — карта мира, Esc — закрыть окно / пауза.
Клавиш ходьбы (WASD) нет.
