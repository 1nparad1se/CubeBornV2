# Макеты интерфейса (hud-01 … hud-24)

Макеты владельца, 1672×941. Общий стиль: почти чёрные панели в тонкой оранжево-золотой пиксельной рамке со ступенчатыми углами, крупные кремовые заголовки с тёмной тенью, золотые основные кнопки, тёмные строки с коричневой кромкой, выбранное — с золотой подсветкой, знак CUBEBORN справа сверху. Реализация: `src/ui/theme.css`, `src/ui/pixelIcons.ts`, `src/rpg2/ui/*`.
