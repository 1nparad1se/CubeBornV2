# Референсы владельца

Картинки, которые владелец прислал как образец. Перед работой над блоками земли, текстурами,
растениями и биомами смотреть сюда. Стиль общий для всех: кубический, пиксельные текстуры из мелких
квадратов (примерно 16 × 16 на грань), мягкий свет, без гладких и «пластиковых» поверхностей.
У каждого блока показан вид кубом (верх и бока) и плоский вид сверху.

## Растения (`plants/`)
Низкие кустики и травы — декор на земле (как трава и кусты сейчас: не мешают ходить, без
ветра). Каждое растение из мелких кубиков-пикселей, на каждой картинке есть вид сбоку, вид
сверху и несколько вариантов-спрайтов. Растут по своему биому.

## Переходы

### Переходы между блоками — [transitions.jpg](blocks/transitions.jpg)
Два материала смешиваются рваными пиксельными пятнами (не ровной линией и не размытым
градиентом), на верху и на боках блока.

| Переход | Смысл |
|---------|-------|
| Трава + земля | частично оголённая земля |
| Трава + камень | камень с участками травы |
| Трава + песок | плавный переход к пляжу |
| Земля + гравий | естественная лесная дорога |
| Камень + снег | заснеженный горный склон |
| Камень + мох | влажные лесные скалы |
| Песок + камень | каменистая пустыня |
| Грязь + трава | заболоченная поляна (с лужицами) |
| Снег + земля | участки тающего снега |
| Песок + глина | переход пустыни в равнину |
